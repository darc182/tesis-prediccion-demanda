# Sistema de predicción de demanda y simulación de reposición de inventario

Trabajo de Integración Curricular.

## Descripción

Desarrollo de una aplicación web para la predicción de demanda y simulación de recomendaciones de reposición de inventario mediante técnicas de aprendizaje automático.

El proyecto utilizará un conjunto de datos público como caso de estudio y contemplará el análisis y preparación de los datos, la experimentación con técnicas de predicción, la evaluación de sus resultados y su integración en una aplicación web.

## Estado del proyecto

En desarrollo.

## Metodología

El proceso de análisis y modelado de datos se organizará mediante CRISP-DM.
